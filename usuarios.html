Política de contraseñas

Se guarda en la base de datos (tabla Configuracion) y el servidor la aplica al crear usuarios, restablecer y cambiar contraseñas. Quien tenga una contraseña que ya no cumpla deberá cambiarla al iniciar sesión. El mínimo permitido es 8.

Aprobación de compras

Los pedidos de compra con total mayor a este monto no se pueden enviar ni recibir hasta que un usuario con permiso "Aprobar compras" los apruebe. Use 0 para no exigir aprobación.
